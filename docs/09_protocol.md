# 09. 연구 프로토콜 (Protocol)

## 1. 연구질문 (PECO)
- Population (P): 대한민국 청소년 (국민건강영양조사/청소년건강행태조사 참여자 중 고등학생 대상 도메인 분석 적용)
- Exposure (E): 아침 식사 결식 (주 n회 이상 결식)
- Comparator (C): 규칙적인 아침 식사 수행군
- Outcome (O): 청소년 비만 유병 여부 (성별·연령별 BMI 95 백분위수 이상 또는 BMI ≥ 25 kg/m²)
- 최종 연구질문: 대한민국 청소년(P)에서 아침 결식(E)이 규칙적 식사군(C) 대비 비만 유병 위험(O)에 미치는 인과적 영향 평가

## 2. 사용 자료 및 가중치
- 사용 자료: 질병관리청 제20차 청소년건강행태조사 (2025년) 원시자료
- 적용 가중치: 청소년건강행태조사 복합표본 가중치(`W`) 및 층화·집락 변수 반영

## 3. 주요 변수 정의표
| 구분 | 변수명 | 라벨 및 코드 정의 | 비고 |
| :--- | :--- | :--- | :--- |
| 결과변수 (Y) | `obesity` | 청소년 비만 유병 여부 (0: 정상/경도, 1: 비만) | 이용지침서 기준 성별·연령별 BMI 백분위수 적용|
| 노출변수 (X) | `breakfast` | 아침 식사 결식 빈도 | 주 n회 미만/이상 구분 |
| 공변량 (Covariates) | `age`, `sex` | 연령, 성별 | 주요 교란변수 |
| 공변량 (Covariates) | `wt_control` | 체중 조절 시도 여부 | **[12주차 민감도분석 대비 추가]** 살을 빼기 위한 시도/행위 관련 문항 |

## 4. 분석 대상 선정 및 도메인 분석 계획
- 분석 대상: 2024년 청소년건강행태조사 전체 참여자 (중1~고3)
- 서브그룹 분석 지침: 고등학생 대상 분석 진행 시, 전체 복합표본의 층(Strata)과 집락(PSU) 분산 추정 구조를 유지하기 위해 데이터 행을 삭제(Filter/Subset)하지 않고 **복합표본 도메인 분석(Domain/Subpopulation Analysis)** 기법을 적용하여 추정함.

## 5. 역할 분담
- 도은민: 연구질문(PECO) 작성 및 프로토콜 문서(`docs/09_protocol.md`) 작성
- 변채은: 원시자료 전처리 및 데이터 확인 노트북(`code/09_data_check.ipynb`) 작성

 
## 6. AI 사용 내역
- 사용 도구: Gemini / ChatGPT
- 프롬프트 내용: "청소년건강행태조사 기반 PECO 연구질문 작성 및 복합표본 도메인 분석 프로토콜 서술 양식 가이드 요청"
- 활용 목적: 프로토콜 마크다운 구조화 및 교수님 피드백 지침(BMI 95 백분위수, 도메인 분석 서술) 문장 다듬기

### 노출변수: 아침식사 결식 (`F_BR`)
- **원 변수명 및 원 코드**: `F_BR` (최근 7일 동안 아침식사를 하지 않은 날수)
  - `1`: 0일 (결식 없음) / `2`: 1일 / `3`: 2일 / `4`: 3일 / `5`: 4일 / `6`: 5일 / `7`: 6일 / `8`: 7일(매일 결식)
- **이용지침서 참조**: 2025년 제21차 청소년건강행태조사 이용지침서 p.34 (식생활 영역)
- **확정 기준**: **주 5회 이상 결식 ($n = 5$)**
  - **비결식군 (0)**: 최근 7일 동안 주 0~4회 결식 (원 코드 `1~5`)
  - **결식군 (1)**: 최근 7일 동안 주 5~7회 결식 (원 코드 `6~8`)
- **기준 선택 근거**: 질병관리청 청소년건강행태조사 국가승인통계 공식 지표('아침식사 결식률')의 정의가 '최근 7일 동안 아침식사를 5일 이상 하지 않은 사람의 분율'이므로, 국가 지표 및 선행 연구와의 비교 타당성을 위해 주 5회 이상을 결식군으로 확정함.
- **고등학생 도메인 대상 집단별 인원 ($N = 25,843$명)**:
  - 비결식군 (주 0~4회): 15,225명 (58.9%)
  - 결식군 (주 5~7회): 10,618명 (41.1%)
