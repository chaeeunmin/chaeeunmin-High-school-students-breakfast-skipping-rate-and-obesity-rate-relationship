# 09. 연구 프로토콜 (Protocol)

## 1. 연구 개요
- **자료명**: 2025년 제21차 청소년건강행태조사
- **연구질문**: 아침식사 결식과 비만 유병의 관련성
- **연구질문 (PECO)**:
  - **Population (P)**: 대한민국 고등학생 (청소년건강행태조사 전체 참여자 중 고등학생 대상 도메인 분석 적용)
  - **Exposure (E)**: 아침식사 결식 (주 5회 이상 결식)
  - **Comparator (C)**: 비결식군 (주 0회 내지 4회 결식)
  - **Outcome (O)**: 청소년 비만 유병 여부 (성별·연령별 BMI 95백분위수 이상)
  - **최종 연구질문**: 대한민국 고등학생(P)에서 아침식사 결식(E)이 비결식군(C) 대비 비만 유병 위험(O)에 미치는 인과적 영향 평가

## 2. 사용 자료 및 복합표본 설계변수
- **사용 자료**: 질병관리청 2025년 제21차 청소년건강행태조사 원시자료
- **복합표본 설계변수**: 가중치(`W`), 층화변수(`STRATA`), 집락변수(`CLUSTER`) 구조 반영

### 노출 및 결과변수 세부 정의
- **아침식사 결식 (`F_BR`)**:
  - **원 코드 의미**: `1`: 0일, `2`: 1일, `3`: 2일, `4`: 3일, `5`: 4일, `6`: 5일, `7`: 6일, `8`: 7일 (이용지침서 p.34)
  - **확정 기준**: **주 5회 이상 결식 ($n = 5$)** [비결식군(0): 주 0회 - 4회 / 결식군(1): 주 5회 - 7회]
  - **기준 선택 근거**: 질병관리청 청소년건강행태조사 국가승인통계 공식 지표('아침식사 결식률')의 정의('최근 7일 동안 5일 이상 결식')를 준용함.
  - **고등학생 도메인 대상 인원 ($N = 25,843$명)**: 비결식군 15,225명 (58.9%) / 결식군 10,618명 (41.1%)
- **비만 유병 여부 (`HT`, `WT`)**:
  - **산출 및 판정**: 자기보고 신장(`HT`)과 체중(`WT`)으로 $BMI = WT / (HT/100)^2$ 계산 후 2020 소아청소년 성장차트 기준 성별·연령별 BMI 95백분위수 이상을 비만으로 정의함.
  - **특성 및 처리**: 자기보고 자료의 한계(신장 과대, 체중 과소보고 경향)를 고려하며, 무응답 및 이상치는 결측 처리함.

## 4. 도메인 및 복합표본설계 확인 (B-1 대상자 인원)

### (1) 복합표본 설계변수 점검
- **원자료 전체 표본 구조**:
  - 전체 응답자 수 ($N$): **54,170명** (중1 ~ 고3)
  - 가중치 (`W`): 유효값 54,170개 (최소 3.66 ~ 최대 298.00, 평균 48.79)
  - 층 (`STRATA`): **117개 층** (유효값 54,170개)
  - 집락 (`CLUSTER`): **800개 집락/학교** (유효값 54,170개)
- **표본설계 유지 지침**: 복합표본의 분산 추정 구조를 왜곡하지 않기 위해 원자료에서 행을 삭제(subset/filter)하지 않고, 전체 54,170명의 표본설계 구조(`STRATA`, `CLUSTER`, `W`)를 그대로 유지함.

### (2) 고등학생 도메인 정의 및 단계별 탈락 흐름 (B-1 Flowchart)
1. **전체 분석 대상 표본**: $N = 54,170$명 (중1 ~ 고3)
2. **도메인 지정 (고등학생, `GRADE` 4, 5, 6)**:
   - 고등학생 도메인 대상자: $N = 25,843$명 (고1: 8,769명 / 고2: 8,604명 / 고3: 8,470명)
   - 도메인 비대상자 (중학생, `GRADE` 1, 2, 3): $N = 28,327$명 (도메인 분석 시 제외 처리)
3. **노출변수(`F_BR`) 유효 인원 점검**:
   - `F_BR` 무응답 및 결측치: 0명
   - 노출변수 유효 인원: $N = 25,843$명 (비결식 15,225명 / 결식 10,618명)
4. **결과변수(`HT`, `WT` / BMI) 유효 인원 및 이상치 제외 점검**:
   - 자기보고 신장(`HT`) 및 체중(`WT`) 미응답/이상치 결측: $N = \text{X}$명 (노트북 출력 수치 반영)
   - 최종 노출·결과 유효 분석 대상자: $N = \text{Y}$명 (Table 1 기본 대상)
